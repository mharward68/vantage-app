## Assumptions made

- **`state.tasks` / `state.taskSettings` are NOT added to the `let state = {...}` literal at app.js:5.** `audienceLists` isn't there either and is the closest precedent; `loadDatabase()` → `ensureStateDefaults()` runs before anything reads state. Simplicity (Ladder 3), reversible.
- **Tasks restore *before* settings in the ZIP branch**, so a settings CSV in the same archive still gets the last word on `Task Date Mode`.
- **The Notes value is never `.trim()`ed on restore** — headers are trimmed and BOM-stripped, values are not. Every sibling restore function trims values; for a field whose whole purpose is holding an email body, leading and trailing whitespace is content.
- **Orphan counting is "does `prospectId` resolve against `state.prospects` right now"** — which in a single-CSV restore means against whatever prospects are currently loaded. In a ZIP restore prospects load first, so the count is accurate there.
- Verification ran against **seed data** (4 prospects: Jane Smith, Alex Rivera, Sarah Chen, Marcus Vance) in the extension-driven Chrome profile — *not* Michael's production database. Confirmed before `wipeAllData()` was called.
