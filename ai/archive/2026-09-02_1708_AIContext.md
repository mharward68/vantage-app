## ⚠️ SECOND PASS — the defect, and why the Done-when missed it

**Michael created "DAV" and "Your AV Dept" fresh, both on `youravdept.com`, and the guard never fired.** He was right.

**The mechanism.** The identity was read from `#comp-domain` alone, and `#comp-domain` was seeded from `#comp-website` **only by that field's own `blur` handler.** So the seed fired for anyone who tabbed THROUGH the Domain box and never fired for anyone who filled Website and went straight to Save — **which is the ordinary way to use the form.** Those records saved with `domain: ""`; an empty domain is deliberately not a collision; the uniqueness guard therefore never ran at all.

**Reproduced here exactly, before changing a line** — and it matches his screenshots field for field (`No address`, `HQ: Unknown`, `General`, a bare `youravdept.com` link):

```
companiesBefore: 6   companiesAfter: 7   warningFired: false
created { name:"DAV", domain:"", website:"youravdept.com", location:"Unknown", industry:"General" }
existingWithThatDomain: ["Your AV Department"]
```

**⚠️ THE LESSON, WHICH IS BIGGER THAN THIS FEATURE. A BLUR HANDLER CAN NEVER BE THE RULE — IT IS ONLY EVER THE DISPLAY.** There is always a way to reach Save without firing it: paste and press Enter, or click Save while the box has never had focus. **The rule has to live at the one place every write passes through.** The fallback is now in `saveNewCompany()`:

```js
const domain = normaliseDomain(
  document.getElementById("comp-domain").value || document.getElementById("comp-website").value
);
```

and a **`#comp-website` blur handler** fills a blank Domain box on screen, so the identity being stored is visible before Save rather than computed behind him. **Both halves are required and neither is redundant** — delete the save-time line and the form is honest but wrong; delete the blur and it is right but silent.

**And the verification lesson: every check in the first pass's Done-when TOUCHED the Domain field, so all eight passed against code that failed the moment nobody did.** A Done-when that only exercises the field the feature is about proves the field, not the feature. **Test the path where the user ignores your new control.**
